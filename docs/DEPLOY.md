# Deploying to Cloudflare Pages

The site is plain static files in `dist/`. Cloudflare Pages builds it from GitHub on every push:
`main` becomes production, and every other branch gets its own preview URL.

## One-time setup (owner, ~10 minutes)

1. Cloudflare dashboard → **Workers & Pages → Create → Pages → Connect to Git**. Pick `jatinmotwani/invoice-tool`.
2. Build settings:
   - Framework preset: **Astro**
   - Build command: `npm run build`
   - Build output directory: `dist`
   - Production branch: `main`
3. **Environment variables.** Set these for Production, and for Preview where noted:

   | Variable                                              | Production                                  | Preview                               |
   | ----------------------------------------------------- | ------------------------------------------- | ------------------------------------- |
   | `NODE_VERSION`                                        | `22`                                        | `22`                                  |
   | `BRAND_NAME`                                          | your brand                                  | same                                  |
   | `SITE_URL`                                            | `https://yourdomain.in` (no trailing slash) | same (canonicals point to production) |
   | `CONTACT_EMAIL`                                       | your address                                | same                                  |
   | `DONATION_UPI_VPA` / `DONATION_PAYEE_NAME`            | your VPA / name                             | same                                  |
   | `SITE_INDEXABLE`                                      | `false` until launch (T4.5), then `true`    | **always `false`**                    |
   | `GOOGLE_SITE_VERIFICATION` / `BING_SITE_VERIFICATION` | tokens from GSC / Bing (M4)                 | leave empty                           |

4. **Custom domain.** Project → Custom domains → add your domain.
5. **Stop `*.pages.dev` from competing with your domain.** Canonicals already point to `SITE_URL`. As an extra step, add a Bulk Redirect from `<project>.pages.dev/*` to `https://yourdomain.in/$1`.
6. **Web Analytics.** Project → Metrics → **Enable Web Analytics**. Cloudflare injects its cookieless beacon; our CSP allows exactly that script (`static.cloudflareinsights.com`) and its endpoint (`cloudflareinsights.com`), nothing else.
7. **AI crawlers.** Cloudflare blocks AI crawlers by default on new zones, and can also rewrite `robots.txt`. The spec wants them allowed. Go to your domain → **AI Crawl Control** (or Security → Bots) and turn off the AI-bot blocking and the managed `robots.txt`. Our own `robots.txt` allows everyone.

## What ships with every deploy

- `public/_headers` sets `frame-ancestors 'none'`, `X-Frame-Options`, `nosniff`, `Referrer-Policy`, `Permissions-Policy`, HSTS and COOP. `/_astro/*` gets long-lived immutable caching.
- Each page carries a CSP `<meta>` tag generated by Astro. It holds hashes for every inline script and style, with no `'unsafe-inline'`.

## Checking a build locally

```
npm run build && npm run serve   # serves dist/ like Cloudflare Pages (clean URLs, 404, _headers)
```
